# Golden vectors

## `device-scheme-vector.json`

The **Device authorization-scheme** vector: an enrolment cert, a possession proof,
the joined `<cert>~<proof>` credential and the full `Authorization` header, all
minted by the **real Go code** — voidbind-go v0.5.0 `enrolment.SignCert` /
`SignPossession` (what heyarr-core vendors) — with fixed seeds and clocks:

- user seed `00..1f`, device seed `80..9f` (Ed25519 is deterministic);
- cert `iat` 1788307200 / `exp` 1796083200;
- possession `now` 1788350400, default 120 s ttl.

Generated by a scratch Go test (not committed to voidbind-go) during the heyarr-mobile
Device-scheme work on 2026-09-02, and carried here unchanged so `DeviceSchemeVectorTest`
proves the library's `PossessionProof` / `DeviceCredential` bytes are exactly what
`enrolment.VerifyPossession` accepts. The same values are inlined in
`commonTest/.../auth/PossessionProofTest.kt` (vector B) so every target runs them.

If a value in this file ever has to change to make a test pass, the wire format
broke — stop and investigate against voidbind-go.
